# Pairwise GSB → SOLO-QA 提交小助手

小助手连接两个固定地址：

- `http://127.0.0.1:8865`：读取已经确认的 Pair、双轨迹和双录像，并回写质检状态。
- `https://solo2.jzxhnh.com`：复用当前 Chrome 登录状态，动态读取本期 GSB 表单、上传四个文件并提交或返修。

正式提交只能从新系统“导出轮次”页发起，并会在上传前弹出确认框。小助手不会读取或保存账号密码。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录。
5. 保持已登录的 SOLO-QA 页面打开，刷新 `http://127.0.0.1:8865/#exports`。

页面显示“提交助手已连接”后即可使用。更新本目录代码后，需要在扩展页点击一次“重新加载”。
